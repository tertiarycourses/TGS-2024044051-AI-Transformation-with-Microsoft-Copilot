# Course source and adaptation notes

The course is original WSQ teaching material informed by, not copied from, the following sources. The two videos are demonstration context; tenant-specific availability and behaviour follow current Microsoft documentation.

- Microsoft AI Transformation Leader (AB-731): https://learn.microsoft.com/en-us/credentials/certifications/ai-transformation-leader/
- Packt AB-731 companion repository (leadership themes): https://github.com/PacktPublishing/AB-731---Leading-AI-Transformation-Across-the-Enterprise
- Microsoft AI Business Professional (AB-730): https://learn.microsoft.com/en-us/credentials/certifications/ai-business-professional/
- MicrosoftLearning AB-730 labs (business task pattern): https://github.com/MicrosoftLearning/AB-730-AI-business-professional/tree/main/Instructions/Labs
- Microsoft Copilot overview video (Tool Finder): https://www.youtube.com/watch?v=bar6CRErgC4
- Microsoft Agent Builder demonstration (Mike Tholfsen): https://www.youtube.com/watch?v=knOhSmOkqMM
- Microsoft Workflows product guidance: https://support.microsoft.com/en-us/microsoft-365-copilot/get-started-with-workflows-in-microsoft-365-copilot
- Microsoft Agent Builder product guidance: https://support.microsoft.com/en-us/microsoft-365-copilot/build-your-own-agent-with-microsoft-365-copilot
- Microsoft agent knowledge guidance: https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/agent-builder-add-knowledge

Workflows availability is tenant-dependent and may require Frontier access. The course includes labelled offline design/testing paths. Agent outputs require source checking and human review; agent knowledge does not guarantee answers are restricted to uploaded sources. No lab uses real personal data or claims that an offline exercise was deployed.
