These are the hands-on lab exercises for the WSQ Microsoft Teams Administrator Associate (MS-700) course delivered by [Tertiary Infotech Academy Pte Ltd](https://www.tertiarycourses.com.sg/).

This repository contains **10 guided Teams administration labs** aligned to the Microsoft MS-700 exam skills measured as of July 29, 2026. The labs cover Teams network planning, security and compliance, governance, external collaboration, devices, teams, channels, chats, apps, meetings, events, Teams Phone, monitoring, reporting, troubleshooting, Microsoft Graph, PowerShell, and Copilot/AI experiences in Teams.

## How to use

1. Read the learner guide first to understand the Teams administrator role and current MS-700 objectives.
2. Open each lab and complete the steps in order.
3. Use a Microsoft 365 developer tenant, trainer-provided tenant, or documentation worksheet depending on available access.
4. Save outputs as notes, policy tables, screenshots, PowerShell snippets, or troubleshooting checklists.
5. Review the checkpoint questions at the end of each lab.
