# AI Transformation with Microsoft Copilot

**TGS-2024044051 · WSQ · v3.0 · 3 days / 24 hours**

A three-day WSQ course for executives and senior managers. Participants use Microsoft 365 Copilot Chat, Word, PowerPoint, Excel, Outlook and Teams for everyday business work; design and test Copilot Workflows with approval and exception paths; and create, test and share a bounded agent in Microsoft 365 Copilot Agent Builder. A synthetic case supports pilot planning, adoption, quality, value and board decisions. Workflows and agent availability vary by tenant; equivalent offline design and testing are provided. The course draws on Microsoft AB-730 business use and AB-731 transformation leadership. It is not exam preparation and requires no coding.

[Official course page and registration](https://www.tertiarycourses.com.sg/wsq-ai-transformation-with-microsoft-copilot.html)

Eligible learners may receive up to 70% WSQ funding; eligibility and terms apply. Check the course page for current fees and funding.

## Learning outcomes

1. Develop technology implementation plans and business processes for Microsoft Copilot.
2. Develop control procedures for Microsoft Copilot to manage security.
3. Evaluate the integration of Microsoft Copilot to ensure alignment with business objectives.
4. Develop optimization plans for Microsoft Copilot to improve business operations.

## Topics covered

1. Use Microsoft 365 Copilot for everyday business work
2. Design safe Copilot Workflows and human controls
3. Create and test bounded Copilot agents
4. Lead adoption, measure value and scale outcomes
