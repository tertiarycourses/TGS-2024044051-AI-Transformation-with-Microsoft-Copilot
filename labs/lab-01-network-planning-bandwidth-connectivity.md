# Lab 1 - Network Planning, Ports, Bandwidth, Network Planner, and Connectivity Tests

## Objective

Plan network readiness for Teams voice, video, meetings, events, and calling.

## Scenario

Contoso has regional offices with inconsistent meeting quality. The Teams administrator must plan bandwidth and validate network readiness.

## Tasks

### Step 1 - Estimate usage

Create:

| Location | Users | Meetings | Calling | Events |
|----------|-------|----------|---------|--------|

### Step 2 - Plan bandwidth

Document capacity assumptions for:

- Audio
- Video
- Screen sharing
- Webinars
- Town halls
- Teams Phone

### Step 3 - Identify ports and protocols

Create:

| Traffic type | Protocol | Port or range |
|--------------|----------|---------------|

### Step 4 - Plan readiness tests

Document:

- Network planner use
- Microsoft 365 network connectivity test
- Teams Network Assessment Tool
- Expected evidence

### Step 5 - Create remediation actions

List actions for poor network results, such as QoS review, firewall rules, local internet breakout, or bandwidth upgrade.

## Deliverable

Submit usage estimate, bandwidth notes, ports/protocol table, readiness test plan, and remediation actions.

## Checkpoint questions

1. Why does Teams media traffic need network planning?
2. What does a connectivity test prove?
3. Which remediation would you prioritize for poor call quality?
